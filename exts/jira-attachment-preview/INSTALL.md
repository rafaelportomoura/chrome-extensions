# Install steps

Steps specific to this extension, inserted into the root `INSTALL.md` by `pnpm zip`. One section
per locale; use `###` headings only.

## pt-BR

### Usar

1. Abra um card do Jira Cloud e clique num anexo .html, .htm, .md ou .markdown.
2. O preview aparece no lugar do código. Use Preview / Source, ao lado do botão de download, para alternar.
3. Open in new tab abre o preview em outra aba.

## en

### Use

1. Open a Jira Cloud issue and click an .html, .htm, .md or .markdown attachment.
2. The preview replaces the code. Use Preview / Source, next to the download button, to switch.
3. Open in new tab opens the preview in another tab.
