# Attachment Preview for Jira

Renders HTML and Markdown attachments inside Jira Cloud's attachment viewer.

## Language

**Attachment viewer**:
Jira's full-screen modal that opens when an attachment is clicked.
_Avoid_: Media viewer, popup, lightbox

**Preview**:
The attachment rendered by the extension, as its author meant it to be seen.
_Avoid_: Render, view, display

**Source view**:
Jira's own view of a text attachment, showing its source code.
_Avoid_: Code view, raw view

**Snapshot**:
A copy of a Preview's content taken when it is opened in a new tab.
_Avoid_: Cache, copy
