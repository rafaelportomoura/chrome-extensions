# Description

What the extension is, for the chat message `pnpm zip` generates. Plain text, one section per
locale.

## pt-BR

Extensão do Chrome que mostra renderizados os anexos HTML e Markdown no visualizador de anexos do Jira Cloud, que hoje só mostra o código.
Útil para revisar protótipos e documentos anexados sem baixar o arquivo.

- Alterna entre o preview e o código com um clique
- Markdown com tabelas, código colorido e diagramas Mermaid
- Abre o preview em outra aba

## en

Chrome extension that renders HTML and Markdown attachments in the Jira Cloud attachment viewer, which otherwise shows only their code.
Handy for reviewing attached prototypes and documents without downloading them.

- Switches between the preview and the code in one click
- Markdown with tables, highlighted code and Mermaid diagrams
- Opens the preview in another tab
