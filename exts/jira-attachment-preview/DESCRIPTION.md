# Description

What the extension is, for the chat message `pnpm zip` generates. Plain text, one section per
locale.

## pt-BR

Extensão do Chrome que mostra renderizados os anexos HTML, Markdown e Excalidraw no visualizador de anexos do Jira Cloud, que hoje só mostra o código.
Útil para revisar protótipos, documentos e desenhos anexados sem baixar o arquivo.

- Alterna entre o preview e o código com um clique
- Markdown com tabelas, código colorido e diagramas Mermaid
- Desenhos Excalidraw com zoom e arrastar, como no Excalidraw

## en

Chrome extension that renders HTML, Markdown and Excalidraw attachments in the Jira Cloud attachment viewer, which otherwise shows only their code.
Handy for reviewing attached prototypes, documents and drawings without downloading them.

- Switches between the preview and the code in one click
- Markdown with tables, highlighted code and Mermaid diagrams
- Excalidraw drawings you can zoom and drag, as in Excalidraw
