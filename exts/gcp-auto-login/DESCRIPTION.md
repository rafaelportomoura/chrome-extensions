# Description

What the extension is, for the chat message `pnpm zip` generates. Plain text, one section per
locale.

## pt-BR

Extensão do Chrome que conclui sozinha o login aberto pelo gcloud auth login e pelo gcloud auth application-default login.
Útil para quem autentica no gcloud várias vezes por dia.

- Escolhe a conta configurada, inclusive no SSO da Microsoft
- Confirma as permissões pedidas e fecha a aba no final
- Só age em logins do gcloud

## en

Chrome extension that completes the sign-in opened by gcloud auth login and gcloud auth application-default login on its own.
Handy if you authenticate gcloud several times a day.

- Picks the configured account, Microsoft SSO included
- Confirms the requested permissions and closes the tab at the end
- Acts only on gcloud sign-ins
