# Install steps

Steps specific to this extension, inserted into the root `INSTALL.md` by `pnpm zip`. One section
per locale; use `###` headings only.

## pt-BR

### Configurar

1. Clique no ícone da extensão.
2. Em Preferred account, informe o e-mail da conta que você usa no gcloud. Se o navegador só tem uma conta Google, pode deixar vazio.
3. Clique em Save.

### Usar

Rode gcloud auth login ou gcloud auth application-default login no terminal. A extensão escolhe a conta, confirma as telas de login e fecha a aba no final.

## en

### Configure

1. Click the extension's icon.
2. In Preferred account, enter the email of the account you use with gcloud. If the browser has a single Google account, you can leave it empty.
3. Click Save.

### Use

Run gcloud auth login or gcloud auth application-default login in the terminal. The extension picks the account, confirms the sign-in screens and closes the tab at the end.
